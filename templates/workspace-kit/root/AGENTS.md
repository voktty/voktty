## How work is organized

This project keeps its shared working memory in `.voktty/`: plans, tracking,
handoffs between sessions, briefs for other agents and the record of who owns
what. At the start of work, read `.voktty/INIT.md` and follow its pointers to
the current context, task, reservations and notes. Maintain that memory as
part of the work and leave a handoff for the next session.

Platform, user and runtime instructions and existing project rules retain
precedence. Read-only requests remain read-only. The kit grants no tool
permissions. Your runtime's private memory is not shared with other agents;
anything they need goes in the project's files.
