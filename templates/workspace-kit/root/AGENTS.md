## How work is organized

This project keeps its shared working memory in `.voktty/`: plans, tracking,
handoffs between sessions, briefs for other agents and the record of who owns
what. When project memory is explicitly enabled for your session, read
`.voktty/INIT.md`, subject to platform, user and runtime instructions and the
existing project rules. The kit grants no tool permissions. Your runtime's
private memory is not shared with other agents; anything they need goes there.

Adding this persistent link is a separate opt-in from enabling memory for
one session. A runtime may continue reading this link independently of
Voktty's local integration setting; remove it explicitly if no longer wanted.
