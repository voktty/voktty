# Domains

One card per component of the project: what it is, how it connects to the
rest, its contracts, how it is built and released, and its traps. Copy
`_TEMPLATE.md` to `<COMPONENT>.md` and write it in the project language.
`PROJECT.md` ("Map") lists the components and links their cards.

Read only the card of the component you are touching. The owner of a
component (see `team/agents.json`) keeps its card current, inside the same
change that alters what the card describes.
