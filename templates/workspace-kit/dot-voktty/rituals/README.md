# Rituals

Recurring tasks that keep the project and its memory healthy. The schedule
is `SCHEDULE.md` (project content, in the project language). The
agent checks which rituals are due at the start of a session and proposes
them; it does not run them without a task. A schedule entry is not an
implemented background trigger or permission to start another agent.

Scripts that automate a ritual live next to these files, one per ritual,
named after it.
